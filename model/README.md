# OpenArm v1.0 bimanual model

This is a dependency-free C11 forward-kinematics, geometric-Jacobian, and bounded position-IK library. It models exactly two chains from `openarm_body_link0` through the named `openarm_{left,right}_hand_tcp` frames in the flattened canonical bimanual v1.0 URDF.

The immutable data was generated by `tools/generate_model.py` from `enactic/openarm_description` commit `6c7b720f1ba48e8bafa3a3dc752c45f397b42221`, source `assets/robot/openarm_v1.0/urdf/openarm_v10.urdf.xacro` with `bimanual=true` and the parallel-link gripper. Upstream lacks a contemporaneous flattened bimanual artifact: extraction parses the checked-in flattened serial chain for the mirrored axes/effective limits and hashes the current xacro/config inputs. The checked-in `example/v1.urdf` is stale for the TCP; extraction validates and applies the current `hand` 0.1025 m and `hand_tcp` 0.0835 m offsets, giving the exact 0.1860 m link7-to-hand_tcp offset. The data file embeds source and canonical-extraction SHA-256 values. Regenerate with:

```sh
python3 tools/generate_model.py /path/to/openarm_description src/generated/oa_model_data.inc
```

`oa_fk` returns body-relative base, pre-joint, post-link, world/body-frame axes, and the selected tip. `oa_geometric_jacobian` is `[linear; angular]`, 6x7, body-frame, row-major. `oa_ik_position` requires a seed, posture reference/weights and explicit numerical controls. It uses adaptive damped least squares, an active feasible set and merit-decreasing steps. Success means only that the requested position tolerance was met within effective URDF joint bounds.

Position IK leaves orientation free; its resulting orientation is returned as `achieved_hand_tcp`. It never checks self, body, other-arm, or environment collision: `collision_checked` is always zero. It is not motion authorization or a collision-safe trajectory planner.

Generated source data and this library retain Apache-2.0 attribution to Enactic, Inc.; see the upstream `LICENSE.txt`. No upstream code or runtime ROS dependency is required.
